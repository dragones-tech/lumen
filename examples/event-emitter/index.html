EventEmitter

A live, no-build example. Served over http, the code below is exactly what runs.

Code

import { EventEmitter } from '../../src/index.js';

// No globals, no side effects — a channel is just an instance.
const bus = new EventEmitter();

// Subscribe; on() returns an unsubscribe handle.
const off = bus.on('ping', (n) => log('ping #' + n));
pingBtn.onclick = () => bus.emit('ping', ++count);
offBtn.onclick  = () => off(); // further emits do nothing

// Group cleanup: one AbortController removes every bound listener.
const ac = new AbortController();
bus.on('tick', () => log('tick'), { signal: ac.signal });
bus.on('tock', () => log('tock'), { signal: ac.signal });
ac.abort(); // removes BOTH at once

Run it

ping is subscribed on its own (no signal). tick & tock are bound to an AbortController. Each is cleaned up by its own path — abort only removes tick & tock, never ping.
