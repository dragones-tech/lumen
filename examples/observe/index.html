observe · reveal-on-scroll, no leaks

Each Card is a View that observes itself with this.observe(...). It slides in the first time it scrolls into the box, then unobserves itself. The observer is bound to the view's signal, so it disconnects automatically on unmount — no disconnect() by hand. Scroll the panel.

Code

import { View, slideIn } from '../../src/index.js';

class Card extends View {
  static template = '#card';
  onMount() {
    this.ui.root.textContent = this.props.label;
    // Bound to signal → the observer disconnects automatically on unmount.
    this.observe(this.el, ([entry], io) => {
      if (!entry.isIntersecting) return;
      this.ui.root.classList.add('seen');
      slideIn(this.el, { duration: 350 });
      io.unobserve(this.el);   // one-shot reveal
    }, { threshold: 0.3, root: scroller });
  }
}
