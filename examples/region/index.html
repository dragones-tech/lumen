Region · a nested layout

An AppLayout View declares static regions (sidebar, main). The sidebar swaps the main region between screens. Dashboard has its OWN nested region — open the console: navigating away tears it down in cascade. Toggle native View Transitions below: on, the browser crossfades (JS animateIn/Out skipped); off, the views' slideIn/slideOut run. Falls back automatically where unsupported.

Code

import { View, slideIn, slideOut } from '../../src/index.js';

class AppLayout extends View {
  static template = '#app-layout';
  static regions  = { sidebar: 'sidebar', main: 'main' };  // auto-created + auto-cleaned
  onMount() {
    this.regions.sidebar.show(new Menu({ onGo: this.go }));
    this.go('home');
  }
  go = (name) => this.regions.main.show(
    name === 'dash' ? new Dashboard() : new Home(),
    { transition: vt.checked },   // native crossfade when supported, else JS animation
  );
}

class Dashboard extends View {
  static template = '#dashboard';
  static regions  = { chart: 'chart' };          // a region INSIDE a region
  onMount()   { this.regions.chart.show(new Chart()); }
  animateIn()  { return slideIn(this.el); }
  animateOut() { return slideOut(this.el); }
}
// Leaving Dashboard unmounts it → empties its chart region → Chart.onUnmount runs. Cascade.

new AppLayout().mount(app);
