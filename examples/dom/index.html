dom · clone + refs

The stateless primitives that views are built from. Markup lives in a <template>.

This page shows clone, refs and $ on their own — low-level plumbing. You will not write views like this by hand. A view is a class that extends the View base class (module 4), which wraps clone + refs + lifecycle + cleanup for you. Here we just exercise the primitives.

Code

import { clone, refs } from '../../src/index.js';

const page = refs(document.body);  // { title, body, build, out }

page.build.onclick = () => {
  const el = clone('#card');     // a fresh node from the <template>
  const ui = refs(el);           // { title, body }
  ui.title.textContent = page.title.value;
  ui.body.textContent  = page.body.value;
  page.out.replaceChildren(el);
};
