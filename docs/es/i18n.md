# I18n

Internacionalización mínima (fase 2). Reemplaza al `translate` del framework anterior.

## Filosofía

- **Diccionarios planos.** Tienes árboles de mensajes por locale; `t(key)` los lee. Sin paso de extracción, sin compilación.
- **Reactivo, amigable con el ciclo de vida.** `setLocale` emite `change`; las vistas se suscriben con `this.signal`, re-renderizan su texto y se limpian al desmontar.
- **Fallback elegante.** Clave faltante → locale de respaldo → la propia clave. Nunca lanza.

## API

| Miembro | Descripción |
|---|---|
| `new I18n({ locale?, fallback?, messages? })` | `messages` es `{ en: {...}, es: {...} }`. |
| `t(key, params?)` | Traduce. Claves con punto (`'home.title'`) y `{placeholders}`. |
| `setLocale(locale)` | Cambia el locale; emite `change` si cambió. |
| `onChange(handler, { signal? })` | Suscribe a cambios de locale. Devuelve unsubscribe. |
| `locale` / `fallback` / `messages` | El estado actual. |

## Ejemplo

```js
import { I18n } from 'lumen/i18n';

const i18n = new I18n({
  locale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}', home: { title: 'Home' } },
    es: { greeting: 'Hola, {name}',  home: { title: 'Inicio' } },
  },
});

i18n.t('greeting', { name: 'Ada' }); // "Hello, Ada"
i18n.setLocale('es');
i18n.t('home.title');                // "Inicio"
i18n.t('missing.key');               // "missing.key" (fallback a la clave)
```

## Dentro de una View

Renderiza el texto en `onMount`, y re-renderiza al cambiar de locale vía `this.signal`:

```js
class Header extends View {
  static template = '#header';
  onMount() {
    this.paint();
    this.props.i18n.onChange(this.paint, { signal: this.signal }); // se quita solo al desmontar
  }
  paint = () => {
    this.ui.title.textContent = this.props.i18n.t('home.title');
  };
}
```

## Notas de diseño

- Construido sobre `EventEmitter`; la suscripción a `change` acepta un `AbortSignal`, así se integra con la limpieza de `View`.
- Sin instancia global — crea un `I18n` y pásalo (props) o importa uno compartido de tu app.
- La interpolación solo reemplaza tokens `{name}`; los placeholders desconocidos quedan intactos (fácil ver parámetros faltantes).
